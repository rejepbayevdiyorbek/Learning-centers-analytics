# 📊 Havas Retail Sales & Transaction Analysis

## 📌 Project Overview
This project presents an interactive Power BI Dashboard designed to analyze sales performance, transaction counts, and product category trends for Havas retail stores. The goal is to provide actionable business insights for store managers and financial decision-makers.

---

## 🔑 Key Features & Dashboard Highlights
- KPI Metrics: Tracked Total Revenue, Transaction Volume, and Average Order Value (AOV).
- Hierarchical Drill-Down: Visualized product categories (Ichimlik / Oziq-ovqat) with seamless drill-down from broad categories to individual items.
- Visual Analytics: Applied conditional formatting for dynamically highlighted metric thresholds.
- Data Model: Structured data transformations in Power Query with optimized DAX calculations for core KPIs.

---

## 🛠 Tools & Technologies Used
- Business Intelligence: Microsoft Power BI
- Data Transformation: Power Query, DAX
- Data Source: Excel / Transaction logs
