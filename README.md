# 📊 Education Center Management & Student Analytics

## 📌 Project Overview
This project features an interactive Power BI Dashboard built to analyze educational center performance, student enrollment trends, course pricing, and completion rates[span_1](start_span)[span_1](end_span). The dashboard provides key insights into branch statistics, course popularity, and revenue distribution.

---

## 🔑 Key Features & Dashboard Highlights
- Core KPI Cards: Tracked total students (150), average course fee ($191.7), course completion rate (100%), and average course duration (56 days)[span_2](start_span)[span_2](end_span).
- Temporal & Trend Analysis: Evaluated average payments by graduation year (2023–2025) and monthly registration dynamics from January to December[span_3](start_span)[span_3](end_span).
- Demographic Breakdown: Visualized gender distribution and corresponding average fees using a professional donut chart configuration (Male vs. Female split)[span_4](start_span)[span_4](end_span).
- Course & Branch Metrics: Analyzed top-performing courses by revenue/fees (Graphic Design, Python, Entrepreneurship, etc.), student counts across various centers, and duration-based distribution[span_5](start_span)[span_5](end_span).

---

## 🛠 Tools & Technologies Used
- Business Intelligence: Microsoft Power BI
- Data Transformation: Power Query, DAX
- Data Source: Excel / Educational Center Database
